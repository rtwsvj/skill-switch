# Codex engineering records

This directory is the audit trail for substantial automated changes.

- `execution-reports/`: approved scope, risks, rollback plan, and intended verification.
- `change-records/`: claims tied to concrete files and commits.
- `verification-reports/`: pre- and post-remediation evidence.
- `session-log.md`: chronological index.

Records are evidence, not a substitute for reviewing the corresponding Git diff and rerunning the listed commands.
